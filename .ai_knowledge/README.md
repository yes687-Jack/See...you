# .ai_knowledge — 公共知识库

本目录存放**跨模块的公共知识**，按知识类型分目录组织。模块内部的局部知识放在各模块自己的 `AGENT.md` 中，不要写在这里。

## 目录约定

| 目录 | 存放内容 |
|---|---|
| `architecture/` | 系统架构、模块划分、数据流、关键机制设计 |
| `conventions/` | 编码规范、工程约定、硬约束、禁止事项 |
| `runbooks/` | 操作手册：构建、发布、排障等可执行 SOP |
| `glossary/` | 术语表、名词与数据结构约定 |
| `templates/` | 知识文档与模块入口的空白模板 |

## 使用规则

1. 新增文档前先判断类型，放入对应分类目录；确实无法归类时先在本文件讨论后再开新分类。
2. 新建文档统一从 [templates/knowledge-doc.md](./templates/knowledge-doc.md) 复制。
3. 每篇文档必须在所属分类目录的 `README.md` 索引表中登记，索引表是该分类的唯一目录。
4. 文档之间用相对链接互相引用；最终应保证从根 [AGENT.md](../AGENT.md) 沿路由可达。
5. 文档只写**稳定、可复用**的知识；一次性的任务进度、临时日志不放入本库。
