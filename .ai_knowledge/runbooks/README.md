# runbooks — 操作手册

> 存放可按步骤执行的操作手册：环境准备、构建发布、常见故障排查、回滚流程等。

## 索引

| 文档 | 说明 |
|---|---|
| [release-branch.md](./release-branch.md) | 版本发布流程：从 main 切 `release/x.y.z`（首个 0.0.0）+ 打 `v` 标签；release 修复按「main 是否需要」评估、经同意后 cherry-pick 回合 |

## 收录标准

- 以「前置条件 → 操作步骤 → 验证方式 → 失败处理」的结构编写，保证步骤可复制执行。
- 命令需注明执行目录与适用环境（开发机 / 离线装置 / 浏览器协议等）。
